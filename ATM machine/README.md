# 🏧 Simple CLI ATM Simulator in Python

A beginner-friendly Command Line Interface (CLI) ATM (Automated Teller Machine) simulator built using **Python**. This project demonstrates basic programming concepts such as loops, conditional statements, error handling, and variable scope management.

---

## ✨ Features

* **Check Balance:** View your current account balance in real-time.
* **Withdraw Money:** Withdraw funds with built-in validation (checks for sufficient balance and valid positive amounts).
* **Deposit Money:** Deposit funds to instantly update your account balance.
* **Error Handling:** Gracefully handles invalid menu inputs (like letters or symbols) and negative numbers without crashing the program.
* **Interactive Loop:** Runs continuously until the user chooses to exit.

---
