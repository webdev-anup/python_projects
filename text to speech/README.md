# 🔊 Python Text-to-Speech (gTTS) Converter

A simple and lightweight Python project that converts text into natural-sounding spoken audio using the **Google Text-to-Speech (gTTS)** library and saves it as an MP3 audio file.

---

## ✨ Features

* Converts any custom text string into spoken audio.
* Supports multiple languages (default is English).
* Automatically exports and saves the output as a `.mp3` audio file.
* Beginner-friendly and easy to run.

---
